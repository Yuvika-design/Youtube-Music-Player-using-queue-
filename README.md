# 🎵 YouTube Music Player (Command-Line)

This is a Python-based command-line music player that lets you queue and play local songs or download audio from YouTube directly. It’s lightweight, easy to use, and demonstrates basic use of data structures and libraries for multimedia.

## ✨ Features

- 🎶 Add songs from local storage
- 📥 Download songs from YouTube (MP3 conversion)
- ▶️ Play, skip, and remove songs from the queue
- 📂 Show current playlist
- 🧠 Uses `deque` for efficient queue handling

## 📦 Requirements

- **Python 3.12+**
- **FFmpeg** installed and added to your system PATH  
  (Download: https://ffmpeg.org/download.html)
